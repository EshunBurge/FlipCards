## ✦ About

An interactive playing-card deck designed for my personal portfolio.

The card deck acts as a visual navigation section, allowing visitors to explore different areas of my work through four custom-designed playing cards.

## ✦ Portfolio Sections

* ♥ **Software Design** — software development and engineering projects
* ♠ **Graphic Design** — visual design and creative work
* ♦ **Science Projects** — research and STEM projects
* ♣ **Just for Fun** — personal projects, interests, and experiments

## ✦ Features

* Custom-designed playing cards
* Interactive 3D card flip
* Hover-based interaction on desktop
* Click-to-flip interaction on touch devices
* Staggered card entrance animation
* Floating card animation
* Responsive layout
* Reduced-motion accessibility support
* Cards function as navigation links

## ✦ Usage

The card deck can be embedded into a personal website by using the HTML structure provided in the portfolio.

Each card contains:

1. A shared card back
2. A custom card front
3. A link to the corresponding portfolio section

Example:

```html
<div class="card-face card-back">
  <img src="CARD-BACK-URL" alt="">
</div>

<div class="card-face card-front">
  <img src="CARD-FRONT-URL" alt="Portfolio section">
</div>
```

## ✦ Purpose

This project was created as part of my personal portfolio to make navigation feel more personal and interactive than a traditional grid of project links.

The playing-card concept gives each area of my portfolio its own visual identity while keeping the interface simple and intuitive.
